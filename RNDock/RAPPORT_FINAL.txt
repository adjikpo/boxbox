🚀 UTILISATION RAPIDE
================================================================================

OPTION 1 : DÉMARRER LE PROJET
  1. cd chemin/Projets/boxbox/RNDock
  2. Lire QUICKSTART.md (5 min)
  3. docker-compose build
  4. docker-compose up
  5. Ouvrir http://localhost:19006

OPTION 2 : CRÉER UN NOUVEAU PROJET
  1. cp -r RNDock ~/MonProjet
  2. cd ~/MonProjet
  3. Lire TEMPLATE_NEW_PROJECT.md
  4. Suivre les 7 étapes
  5. docker-compose build && up

OPTION 3 : AVOIR UN PROJET EXISTANT
  1. cp les fichiers Docker
  2. Adapter docker-compose.yml
  3. docker-compose build
  4. docker-compose up

🔧 COMMANDES ESSENTIELLES
================================================================================

MAKEFILE
  make help              # Voir toutes les commandes
  make build             # Construire les images
  make up                # Démarrer (background)
  make dev               # Démarrer (foreground)
  make logs              # Voir les logs
  make clean             # Nettoyer tout

DOCKER COMPOSE
  docker-compose build                 # Builder
  docker-compose up                    # Démarrer
  docker-compose ps                    # Voir containers
  docker-compose logs -f               # Logs
  docker-compose down                  # Arrêter
